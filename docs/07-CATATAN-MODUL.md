# Catatan status modul

| Modul | Status |
|---|---|
| CRM, pelanggan, penawaran, pesanan | Implementasi tersedia; izin aksi diperketat |
| Invoice dan pembayaran | Penguncian konfirmasi dan transaksi bersama |
| Produksi, inventaris, pengiriman | Aturan QC, stok, dan transisi diperketat |
| Payroll, kasbon | Finalisasi/jurnal atomik; cicilan kasbon belum tersedia |
| Akuntansi, laporan, KPI | Koreksi rupiah, akun gaji/piutang karyawan, dan neraca |
| Notifikasi | Tanda baca per pengguna dan batas cabang |
| Hutang | Belum tersedia |
| Integrasi BSI dan WhatsApp | Memerlukan konfigurasi serta uji staging dengan provider |

Lihat Panduan untuk prosedur kerja. Kehadiran modul tidak berarti seluruh alur telah diverifikasi dengan data produksi.
